# Messenger
## Назначение
Микросервис внутреннего мессенджера в проекте [Farm](https://github.com/mongolianpes/Farm)
Позволяет обмениваться сообщениями, получать список чатов и их историю

## Функционал
- Возвращает список своих чатов.
- Позволяет получить историю чата кусочками нескольких сообщений.
- Позволяет отправлять сообщения другим пользователям. При отправке первого сообщения создает чат. В случае если у отправленого сообщения нет получателя или объявления, на основе которого начинается(было начало) общение, отправка сообщения невозможна.
Примечание: с одним пользователем можно иметь сразу несколько чатов, поскольку каждый чат создается между двумя пользователями на основе объявления. В случае если нет привязки объявлению создание чата невозможно.

## RPC запросы:
```
service Messenger {
    rpc GetChats(GetChatsRequest) returns (GetChatsResponse);
    rpc SendMessage(SendMessageRequest) returns (SendMessageResponse);   
    rpc GetChatHistory(GetChatHistoryRequest) returns (GetChatHistoryResponse);
}
```
Подобнее в файле Messenger/proto/messenger.proto

## Переменные окужения
Для корректной работы необходимы переменные окружения:
DB_HOST - адрес БД
DB_PORT - порт БД
DB_USER - пользователей БД
DB_PASSWORD - пароль пользователя БД
DB_NAME - название БД
